Términos y condiciones

Nova Launcher es un proyecto independiente para administrar instancias de Minecraft Java Edition. Minecraft es una marca de sus titulares. Nova es un producto de terceros sin afiliación ni aprobación de Mojang o Microsoft.

Uso del launcher

Usá Minecraft y el contenido de terceros de acuerdo con sus licencias y condiciones. Los servidores pueden exigir una cuenta autorizada, versiones concretas o sus propias reglas de acceso.

Nova se distribuye como beta. Conservá una copia de los mundos que quieras guardar antes de actualizar una instancia o cambiar sus mods.

Privacidad

Nova guarda las instancias, los perfiles offline, las direcciones de servidores y los registros del juego en el equipo. Cuando usás funciones en línea, el launcher se conecta al proveedor correspondiente, como Microsoft, Modrinth, CurseForge o GitHub.

La web está alojada en Vercel y consulta GitHub Releases para mostrar la versión disponible. Al abrir enlaces externos o descargar desde GitHub, se aplican las condiciones y prácticas de privacidad del servicio que recibe la solicitud.

Soporte

Podés reportar errores del launcher en GitHub. Antes de compartir un registro, revisá si contiene datos personales, direcciones privadas o credenciales.
